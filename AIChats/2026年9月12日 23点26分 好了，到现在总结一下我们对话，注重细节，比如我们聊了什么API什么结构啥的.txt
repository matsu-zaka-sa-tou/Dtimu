[ApiController]
[Route("api/albums")]
public class AlbumsApiController : ControllerBase
{
    [HttpGet]
    public IActionResult Get([FromQuery] string name)
    {
        if (string.IsNullOrWhiteSpace(name)) return BadRequest(...);
        var albums = Program.DireInfo?.Albums;
        if (albums == null || !albums.ContainsKey(name)) return NotFound(...);
        return Ok(albums[name]);
    }
}

五、Bug 与修复
Bug 1：悬停预览框背景色一直变
原因：

第二个 script 里的 coverUrl(item) 没有缓存，每次 mouseenter / mousemove 都重新跑 generateCoverSvg

生成器里的 pickColor() 当时还是 Math.random() 版本

修复：

pickColor(text) 改成 FNV-1a 哈希：

js
function pickColor(text) {
    let h = 2166136261 >>> 0;
    for (const ch of (text || '')) {
        h ^= ch.codePointAt(0);
        h = Math.imul(h, 16777619) >>> 0;
    }
    const c = COLORS[h % COLORS.length];
    return `rgb(${c[0]},${c[1]},${c[2]})`;
}
coverUrl 加 Map 缓存：

js
const _svgCache = new Map();
function coverUrl(item) {
    if (item.pictures?.length) return '/Cover/' + encodeURIComponent(item.pictures[0]);
    let url = _svgCache.get(item.key);
    if (!url) { url = coverSvgDataUrl(item.key); _svgCache.set(item.key, url); }
    return url;
}
Bug 2：@{.txt 整体崩掉
原因：第二个 script 里 coverUrl 没缓存 + 生成器里还是随机 pickColor()。

修复：两个脚本全部重写——生成器用哈希色，coverUrl 加缓存。这份就是最终可用的完整版。

八、关键设计原则
二进制通过 URL 走缓存，不内联 base64。

URL 注入用 JsonSerializer.Serialize，前端 URL 参数用 encodeURIComponent。

颜色用内容哈希（FNV-1a）而不是随机——同一输入永远同一输出。

前端生成有缓存（Map）——同一专辑名只跑一次生成器。

C# 是视觉规范，JS 是复刻——两边的 14 色数组、字体顺序、0.68/0.72 系数、22/18/220/165 边距、25→15 缩放全部对齐，这样无论走前端还是后端生成，观感一致。

@guid 隔离：同一页面多次渲染这个组件不会撞 id（cardBase、albumGrid、preview 都从 cardBase.querySelector 取，不污染全局）。
