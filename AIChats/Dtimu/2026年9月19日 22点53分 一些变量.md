
# 一些变量

记录项目中涉及状态判断的静态变量及其含义。

## 变量一览

| 变量 | 类型 | 说明 |
| --- | --- | --- |
| `IsBurned` | `bool` | 该目录是否为烧录后的目录；烧录后的目录不允许上传（修改）文件 |

## `IsBurned`

> 该目录是否为烧录后的目录，烧录后的目录不允许上传（修改）文件。

```csharp
/// <summary>
/// 该目录是否为烧录后的目录，烧录后的目录不允许上传（修改）文件。
/// </summary>
public static bool IsBurned { get; set; }
```

**要点**

- 使用 `static` 属性，属于全局状态，跨请求共享。
- 类型是 `bool`，直接判断真/假即可，无需空值检查。
- 语义上是「目录状态」开关，用于控制上传（修改）文件是否被允许。
